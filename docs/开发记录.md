## 2026-10-13 — v3.1.0：miniapp 打包分享 · 后台前置 · 体验修补

- **miniapp 导入导出**（`system/apphost/miniapp.py`，新）：App 可打包为 `.miniapp`（zip）分享。
  manifest 新增可选 `requires` 字段声明依赖（`shared` 模块名 / `py` import 名，`pip:` 前缀强制按
  pip 包名）。导出时整模块打包 shared（数据库 *.db、data/ 目录绝不进包），纯 Python 第三方库随包
  拷贝，带二进制的库自动转入 pip_required 清单；导入时缺的 shared 补齐（已有则跳过不覆盖）、
  pylibs 解到 `data/pylibs`（已入 sys.path）、pip_required 自动 `pip install --target`（失败不阻断）。
  zip slip 双重防护；id 冲突可选覆盖。左侧列表右键 App → 导出；「新建 App」子菜单 → 导入。
- **后台前置**：左上折叠按钮改为「后台」入口——点 Tab 图标：当前 Tab 再点折叠、否则跳转；
  后台按钮展示后台 App 列表（前台/后台状态 + 运行时长），右键变更为 切前台 / 重启 / 终止；
  原「程序」面板保留并补运行时长展示。`AppFrame.restart()` 落地（teardown → 销毁 → 后台重挂）。
- **状态记忆（仅运行时，不落盘）**：分区切换不再把折叠的文件夹重置为展开（tree.js collapsedFolders）；
  控制台切换记住上次条目（shell.js consoleItem）。
- **bug 修复**：自动化触发器下拉首次选择不刷新（菜单挂 body 不冒泡，加显式 onChange 回调）；
  删除 App 管理遗留的自启动按钮与机制（自动化「中枢启动时」触发器已可完全替代，全链路移除）；
  图标选择改为仅 SVG（后端同步校验后缀）。
- **小修（遗留清单择要）**：URL 型 App 挂载前校验 scheme 只放行 http(s)；GYun create/update/batch
  与 client 注入改浅拷贝，不再污染调用方原始 dict；entity_storage 强制 entity_id/create_time 以
  入参为准；duplicate_app 复制 id 加时间戳避免撞名；pick_files 兼容 SAVE_DIALOG 返回单字符串；
  automation 调度器类变量改实例惰性初始化（防 Api 多实例串状态）。
- 测试：149 项全绿（新增 tests/test_miniapp.py 7 项，删自启动相关 1 项）。
